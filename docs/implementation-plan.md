# Android 开发计划

## 已完成

- 产品 UI 原型
- 液态玻璃视觉和真实水族馆背景
- 真实鱼类素材和鱼类动画
- 鱼类点击档案交互
- 所有场景开放状态
- 36 个住客条目，包含鱼类、贝类和其他水族生物
- `AquariumCatalog.kt` 统一目录，收拢全部场景与住客数据
- Compose Android 工程
- Lock Task Controller 入口
- Debug APK 构建

## 下一阶段

### 禅定会话

- 建立 `FocusSession` 状态模型
- 使用前台服务保证倒计时在后台持续
- 处理暂停、恢复、完成和异常退出
- 禅定完成时发放金币

### 锁定态

- 建立独立的 Lock Activity 状态
- 加入白名单摘要区域
- 增加天气、待办和当前场景状态
- 在真机上验证 Lock Task 和退出路径

### 数据持久化

- Room 保存鱼类、场景、金币和专注记录
- DataStore 保存用户设置和白名单
- 设计迁移和恢复策略

### 系统接入

- NotificationListenerService
- Android 日历或本地待办入口
- 天气数据源
- 通知权限和必要的系统设置引导

## 验收标准

- Debug APK 可以安装并打开首页。
- 鱼类点击交互和页面导航正常。
- 完成一轮模拟禅定后金币状态一致。
- 锁定态在支持的设备配置上能够进入和退出。
- 电话、短信和白名单摘要策略在至少一台真机上验证。
