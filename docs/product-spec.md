# 深海禅定产品说明

## 产品定位

深海禅定是一款把番茄时钟、Android 锁定态和水族箱收藏结合起来的专注工具。用户用一轮禅定换取金币，再用金币购买鱼苗和水域，让专注结果变成可持续成长的水族箱。

## 核心循环

1. 用户选择场景和禅定时长。
2. 应用进入锁定任务入口，显示水族箱和允许展示的信息摘要。
3. 用户完成禅定后获得金币和专注记录。
4. 用户使用金币购买鱼苗或场景。
5. 鱼类根据专注进度积累亲和度，并在水族箱中游动。

## 第一版界面

### 我的水族箱

- 全应用横屏，水族房使用沉浸式全屏
- 当前场景和真实水族馆背景
- 水族房内的天气和 Todo 玻璃侧栏
- Todo 支持新增、点击完成和删除
- 禅定时长支持 25、50、90 分钟切换
- HUD 默认隐藏，触摸水族房后显示 5 秒
- 25、50、90 分钟禅定入口
- 鱼类游动和点击档案
- 住客档案支持手动关闭
- 鱼苗投放后显示在当前场景内
- 最近禅定记录
- 场景开放状态和金币余额

## 交互规则

- 点击或键盘聚焦鱼类时显示住客档案。
- 鱼类档案包含名称、习性、性格、稀有度、水域和亲和度。
- 点击鱼苗卡片时显示对应档案。
- 点击“投放”后，鱼苗加入当前场景并出现在水族房内。
- 触摸水族房后显示导航、Todo、天气和禅定操作，5 秒无触摸后自动隐藏。
- 点击开始禅定时先展示锁定确认对话框。
- 当前 Web 和 Android 第一版使用本地静态数据，后续再接入持久化和真实系统信息。
